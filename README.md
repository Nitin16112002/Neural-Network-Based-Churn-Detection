# Neural-Network-Based-Churn-Detection


This project implements an Artificial Neural Network (ANN) to predict customer churn using demographic and financial data from a retail bank. The goal is to help the business proactively identify customers at risk of leaving and take preventive action.

---

## 📊 Business Problem

Customer churn directly impacts a bank’s revenue and growth. By predicting churn early, banks can engage customers with personalized retention strategies. This project aims to leverage machine learning—specifically neural networks—to forecast churn based on customer attributes such as age, credit score, account activity, and more.

---

## 🔍 Project Overview

- Designed and trained an ANN model using Keras/TensorFlow.
- Input data includes features like:
  - Credit Score
  - Age
  - Tenure
  - Balance
  - Number of Products
  - Active Membership
- Performed preprocessing (scaling, encoding, train-test split).
- Evaluated model performance using accuracy, confusion matrix, and classification metrics.

---

## ✅ Results

- **Model Accuracy**: 85.6%
- **Churned Customers Correctly Identified**: 151
- **Retained Customers Correctly Identified**: 1561
- Demonstrated strong class separation and high predictive power.

## 📌 Conclusion

The neural network effectively predicts customer churn by identifying key patterns in financial and behavioral data. With high accuracy, the model offers actionable insights that can directly support strategic decisions for customer retention and revenue protection.
